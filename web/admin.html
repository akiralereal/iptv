🧳 配置备份 / 迁移
一键把全部配置（系统配置、外部源、我的频道与各配置档、EPG 源、别名 / 分组规则、用户令牌）导出为单个备份文件；换机 / 重装后导入即可恢复。⚠️ 导出文件包含咪咕账号与访问密码，请勿随意发给他人；自定义台标 logos/ 文件夹不在包内，如有请单独拷贝。
导入会覆盖当前同名配置（导入前会自动把当前配置备份到数据目录 config-pre-import-backup.json，写坏可手动恢复）；导入后多数配置即时生效，端口修改需重启。
🔤 频道别名（统一命名规则）
给上面的「统一频道显示名」加自定义规则：把若干别名都归到一个规范名下（如 规范名 CCTV5体育，别名 央视5套, 体育频道）。内置规则（CCTV 系列、清晰度后缀等）已覆盖大部分，这里只补兜不住的写法。保存后下次刷新播放列表即生效。
🗂️ 关键字自动分组
自定义订阅源里没写分组的频道会落到「未分组」，每次刷新又回到未分组。这里按频道名关键字配规则，名字含关键字的未分组频道会自动归到对应分组（多条规则按从上到下、首条命中生效）——刷新也不丢，且不影响源已分好的分组、手动移动优先。如 分组 央视 ← 关键字 CCTV, 央视。保存后下次刷新播放列表即生效。
📅 EPG 节目单源（聚合）
把外部 XMLTV 源的节目单归一后合并进 /playback.xml，给咪咕未覆盖的频道补节目单。默认已开启、内置默认源，开箱即用。改动即时保存、无需重启，下次更新生效（或点「立即刷新」）。
优先级数字小者优先；多源命中同一频道取高优先级。咪咕已有的频道始终优先，外部不会覆盖。
👤 用户管理（一人一源）
给每个家人 / 朋友生成独立的源地址 /u/<令牌>/m3u，可单独停用、泄露可追溯，且令牌进不了本后台。不新增用户则对现有链接零影响。
怎么用
① 点「➕ 新增用户」，给每个人起个名（如「客厅电视」「老王」）；
② 用每行的「📋 复制 m3u」把各自的源地址发给对应的人；
③ 谁的链接泄露 / 不想给了 → 关掉那一行的开关（或「🔁 重置令牌」），只影响他一个，其他人照常。
注意
• 这是「可追溯 + 可单独吊销」，不是「漏了也用不了」——发现异常停掉即可；
• 你自己的站长密码不要外发（它能进后台）；发出去的只该是 /u/<令牌>/…；
• 「绑定档」可给不同人不同频道，不选就是默认全量。
