使用说明

自定义源配置
  1. 点击"添加自定义源"选择模式：直连模式、抓取模式或订阅模式
  2. 想加回港澳台等网络第三方频道：点「添加「来源于网络」列表」，再点"导入并保存"
  3. 抓取模式：填写频道名、分组和网页地址，点击"抓取并保存"
  4. 直连模式：填写频道名、分组和m3u8链接，点击"保存"
  5. 可编辑、删除、启用/禁用
  6. 设置自动刷新间隔（默认4小时）
平台自带的抓取模块。每个模块一个开关，点了立刻生效、无需保存；关掉即不联网、 不出现在播放列表，配置原样保留、开回来即恢复。关掉的模块显示为灰色，可按开关筛选。
随程序自带的内容，由维护者策展、不可编辑。每项一个开关，关闭后对应内容不再加载，可能导致频道大幅减少。
内置单频道源 内置
自带的抓取型单频道源（当前为 纬来体育，清单随远程配置更新）；关闭后不加载也不抓取，省启动资源
内置订阅源 内置
自带的 精选频道（央视 / 港澳台 / 地方 / 国际），约 150 个频道。随程序更新，不可编辑。
关闭后这些频道不再出现在播放列表里，随时可以开回来
访问与安全
服务怎么被访问：端口、对外地址、访问密码和后台路径。
Docker 部署还需同步改端口映射。
选填。填 http(s)://… 完整地址时原样使用（不写端口即 80/443，适合内网穿透/反向代理）；只填 ip/域名则自动补 http:// 和上方的服务端口
设置后访问格式：http://ip:port/密码/...
自定义后台地址（默认 admin），如填 console 则用 /console 访问，/admin 将失效（api / player / favicon.ico 为保留字）
更新与显示
多久全量更新一次，以及频道名怎么显示。
⚠️ 咪咕频道 / EPG / 体育的全量更新间隔。如果填写了咪咕 Token（登录账号），建议设置 8 小时以上——过于频繁请求可能触发风控、影响账号。
开启后，把不同订阅源里同一个台的不同写法（如 CCTV1 / CCTV-1 / CCTV1综合）按内置规则自动统一成同一个显示名（CCTV 系列、清晰度后缀等已内置）。默认关；手动重命名优先级更高；规则兜不住的写法可在「频道别名」标签里加规则。
标了「需重启」的项保存后要重启服务才生效；其余项保存即生效。
频道别名（统一命名规则）
给上面的「统一频道显示名」加自定义规则：把若干别名都归到一个规范名下（如 规范名 CCTV5体育，别名 央视5套, 体育频道）。内置规则（CCTV 系列、清晰度后缀等）已覆盖大部分，这里只补兜不住的写法。保存后下次刷新播放列表即生效。
关键字自动分组
自定义订阅源里没写分组的频道会落到「未分组」，每次刷新又回到未分组。这里按频道名关键字配规则，名字含关键字的未分组频道会自动归到对应分组（多条规则按从上到下、首条命中生效）——刷新也不丢，且不影响源已分好的分组、手动移动优先。如 分组 央视 ← 关键字 CCTV, 央视。保存后下次刷新播放列表即生效。
EPG 节目单源（聚合）
把外部 XMLTV 源的节目单归一后合并进 /playback.xml，给咪咕和各模块官方节目单都没覆盖的频道补节目单。默认已开启，但不带内置外部源，需要更广覆盖时点「＋ 添加 EPG 源」自己加。勾了「优先于官方节目单」的源，对它当前有节目的频道会覆盖咪咕和各模块的官方节目单（源停更只剩旧数据时自动让回官方）。改动即时保存、无需重启，下次更新生效（或点「立即刷新」）。
优先级数字小者优先；多源命中同一频道取高优先级，勾了「优先于官方节目单」的排在最前。没勾的源只补咪咕与各模块官方节目单都没有的频道。
用户管理（一人一源）
给每个家人 / 朋友生成独立的源地址 /u/<令牌>/m3u，可单独停用、泄露可追溯，且令牌进不了本后台。不新增用户则对现有链接零影响。
⚠️ 还没设访问密码，一人一源等于没生效：去掉令牌的地址（如 http://ip:端口/m3u）谁都能直接用，后台也没上锁。请先到 系统配置 设置「访问密码」；已发出去的 /u/<令牌>/… 链接不受影响。
怎么用
① 点「＋ 新增用户」，给每个人起个名（如「客厅电视」「老王」）；
② 用每行的「复制 m3u」把各自的源地址发给对应的人；
③ 谁的链接泄露 / 不想给了 → 关掉那一行的开关（或「重置令牌」），只影响他一个，其他人照常。
注意
• 这是「可追溯 + 可单独吊销」，不是「漏了也用不了」——发现异常停掉即可；
• 你自己的站长密码不要外发（它能进后台）；发出去的只该是 /u/<令牌>/…；
• 「绑定档」可给不同人不同频道，不选就是默认全量。
消息推送
后台顶部「需要处理的提醒」出现新的一条（登录凭证失效、模块抓取失败、EPG 源失败等）或问题恢复时，发一条消息到飞书、企业微信、钉钉、Telegram、Bark 或你自己的 Webhook，不用开着后台也能知道。只发消息，不接收任何指令。
• 抓取失败要连续失败两次才发，一闪而过的不打扰；其他提醒出现即发，恢复时再发一条「已恢复」；
• 升级前就已存在的提醒不发；同一个问题没恢复前只发一次；
• Telegram 的接口在大陆连不上：部署在大陆需给容器设 HTTPS_PROXY，或在「API 地址」填自己的反代；
• 机器人地址和 Token 存在数据目录 notify-channels.json，会随「备份迁移」里的配置导出一起导出，别把备份发给别人。
配置备份 / 迁移
一键把全部配置（系统配置、外部源、我的频道与各配置档、EPG 源、别名 / 分组规则、用户令牌、消息推送）导出为单个备份文件；换机 / 重装后导入即可恢复。⚠️ 导出文件包含咪咕账号、访问密码与推送机器人地址，请勿随意发给他人；自定义台标 logos/ 文件夹不在包内，如有请单独拷贝。
导入会覆盖当前同名配置（导入前会自动把当前配置备份到数据目录 config-pre-import-backup.json，写坏可手动恢复）；导入后多数配置即时生效，端口修改需重启。
