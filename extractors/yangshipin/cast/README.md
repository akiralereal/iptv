# 央视频投屏来源

后台使用央视频模块的 `uhdSource` 枚举：默认 `cast` 只有 CCTV4K、CCTV16 4K、CCTV8K 走投屏；`all`（issue #240）让引擎支持设备协议的 26 台（CCTV1～17 除 CCTV6、CCTV5+、三台超高清、6 个 CGTN）都走投屏；`main` 全部用原方案。沿用现有配置校验、落盘、备份、管理员鉴权和表单。

台名、引用、台标、EPG与订阅URL不变。网关按路径认领这 26 台，入口按当前设置分流：没选 `all` 时普通台回 null，交回原方案的通用流程（清单直出、libVLC 视图等照旧）。走投屏的入口返回单档主清单，子清单固定到当前选择；密码或用户令牌前缀贯穿清单和分片。保存来源只影响新开播。普通公开台及VIP桥不进入本组件，未引入实验台的VIP待命或补缓冲修改。

## 运行

- Docker 已有 Python 3，不增加 pip 依赖。源码运行需 Python ≥3.9，可用 `YSP_CAST_PYTHON` 指定可执行文件。
- 首次请求投屏媒体清单才启动一个内部进程，监听动态回环端口，无新增对外端口、不依赖实验台1928服务。
- 所有投屏频道共享一个进程和一个设备身份、并发请求合并。设备同时最多挂 6 个不同频道（上游 `links_per_device`，空闲 15 秒释放），超出的我们不退回 1080P，直接 503。设备状态保存在本部署数据目录 `yangshipin/cast-device/`，不读取会员登录态，不复制实验台设备身份。
- 最后一次媒体请求后空闲约3分钟退出；父进程退出也会结束内部服务。启动失败退避30秒，避免连续注册。
- 首次设备初始化可能额外耗时；HEAD、OPTIONS、订阅读取、设置保存不启动设备服务。
- 内部服务只提供这 26 台设备流（worker 不再带 `--only-4k`，频道白名单等于引擎的 `BACKEND_CHANNELS`），不提供第三方EPG或JCE/BK/Node降级链。失败由当前来源返回错误，用户手动切回原方案。设备协议本身的换票、缓存、冷却与恢复保留。
- 媒体流式转发，保留Range、状态和字节数，不改编码或时间戳。唯一的改动是隐藏 Audio Vivid（菁彩声）音轨：投屏流在 AAC 前多一条 `stream_type 0xd5`、注册描述符 `av3a` 的三维声轨，播放器解不了，ffmpeg 还常把它误探成 22050Hz 8kbps 的 mp3，mpv 等按第一条音轨选的播放器就没声音（issue #241）。`ts-audio-filter.js` 从 PMT 删掉这一项并重算 CRC、把它的包整包换成空包，长度不变；只有这一条音轨或它带 PCR 时保留，不是 TS、失去同步、Range 不从包边界开始时原样转发。只能请求实际清单登记的匿名媒体ID，不能提交任意代理URL。客户端断开时释放上游连接。
- 不向投屏服务传Cookie、Authorization、访问密码或用户令牌。日志不透出原始取票错误、设备身份和签名地址。

## 来源与适配

`vendor/ysp-live.py` 原样来自 [waastudios/ysptp-docker v9.5.0](https://github.com/waastudios/ysptp-docker/tree/b7c0fb3e6cc372c362ddf10caae39bf641ea81c2)。提交和SHA256见 `vendor/UPSTREAM.json`，加载时校验；作者信息保留在源码中。本目录是iPTV集成适配，不是上游作者发布的版本。

`pool.py`、`transport.py` 迁入实验台验证过的连接复用及取票内两处等待优化，关闭实验事件落盘。`quality.py` 保留档位选择、移除实验采样。频道名中的8K不代表实际尺寸；目前实测为3840×2160。

`ts-audio-filter.js` 只在网关转发分片时隐藏 Audio Vivid 轨，见上文。

`worker.py` 限定频道/接口、禁止跨来源兜底、设置动态回环端口和父进程退出处理。原协议源码未改写。`process.js` 管进程；`gateway.js` 负责鉴权后的媒体路由。NAS资源和长期稳定性仍需部署后观察。

## 验证

- `node --test scripts/test-ysp-cast.mjs`：来源固定、入口与HEAD不取流、并发合并、媒体字节/Range、Audio Vivid 轨隐藏（任意分块、长度不变、保留条件）、目标白名单、凭据隔离、断开取消、进程回收与退避。
- `python3 -B scripts/test-ysp-cast-worker.py`：原模块哈希、频道白名单、禁止其他来源请求、失败冷却；无网络。
- `node scripts/test-yangshipin-app-route.mjs`：真实HTTP密码/用户令牌、设置切换、普通台与VIP回归。
- `npm test`：完整项目回归。
