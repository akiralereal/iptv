单独存成一个文件

这些地址来自网友搭的转发站，不是电视台官方源，本项目不维护、不保证能播。复核后已从内置精选列表移出，统一备份在 from-the-web.m3u；以后从网络收集到的其它链接，也会继续备份到这个文件里。

1点「来源于网络」卡片

打开源管理
点「来源于网络」这张卡片

打开 iPTV 后台「🌐 源管理」里的「👤 自定义源」，点那张带 🌏 的「来源于网络」卡片，订阅名称和列表地址会自动填好，不用抄地址。

!已经加过的话这张卡片不再出现，列表就是那张名为「来源于网络」的源卡片。
http://你的NAS地址:1905/admin

＋添加自定义源
🌏添加「来源于网络」列表港澳台、新马、影视等网络第三方频道
↑ 点这张卡片
2导入并保存

表单已经填好
点「导入并保存」

订阅名称和列表地址都已自动填好，直接点「📥 导入并保存」，频道按地区分组进入「我的频道」；以后文件里新收录的链接，订阅刷新后自动出现，不用再加一次。

!列表在国内会自动回退 GitHub 镜像拉取；但频道能不能播，取决于你的网络能否访问海外。

新收录的链接自动出现

以后备份进 from-the-web.m3u 的其它网络链接，订阅定时刷新后自动进入列表，不用重新添加。

!

不保证能播

第三方转发站随时可能失效，国内直连基本播不了；失效条目不作为 bug 处理，删掉这条订阅即可全部移除。

≠

不进默认列表

内置精选列表只留复核通过的地址；这份清单只给需要的人自己加，其他用户不受影响。
