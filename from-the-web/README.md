[from-the-web.m3u](from-the-web.m3u) 是「来源于网络」自定义订阅，当前包含 **29 个第三方转发频道、4 个正规平台分发频道、1 个具体来源待确认的 CDN 频道**，在文件中分区标注。第三方转发源大部分原本在内置精选列表 `IPTV.m3u` 里，v4.7.0 逐条复核后移出（翡翠台与三条凤凰线路 2026-10-22 移出）；2026-10-26 又按 [issue #202](https://github.com/akiralereal/iptv/issues/202) 收了网友提供的一批 `cdn3.indevs.in` 地址。2026-11-08 从 `IPTV.m3u` 移入 Pet Club TV、WildEarth、World Poker Tour、NHL FAST、Love Nature 4K，保留原播放地址、分组和台标，并删除纬来日本、纬来育乐。World Poker Tour 同日移除「亚洲与国际直播」模块入口，仅由本订阅提供。放在这里只是方便有需要的用户自己添加，**本项目不维护、不保证可用，失效条目不作为 bug 受理**。

## 可用性（2026-09-07 复核，2026-10-26 海外重测）

以下为原第三方转发源的历史复核记录，不适用于 2026-11-08 移入的 5 个频道；新移入频道本次未重新探测，不能套用「大陆直连全部不可达」的结论。

- **大陆直连全部不可达**：转发站域名在电信 / 联通 / 移动家宽和腾讯 / 阿里机房共 9 个探针上均被 DNS 污染、无法建立连接。只有海外网络或路由器级全局代理环境才能播。2026-10-26 新收的 `cdn3.indevs.in` 没做大陆复核，同样按需要海外网络看待。
- 2026-09-07 海外视角逐条拉取了清单与首个媒体分片，均能取到数据；MOMO 亲子台复核时已失效，未收录。
- 2026-10-26 在 GitHub Actions 美国东部 runner 上用 `scripts/probe-m3u.mjs` 深度探活（拉主清单、子清单，再下一段分片）：全部 HLS 条目都能取到数据，包括 10-22 移入的翡翠台、凤凰三条线路和 14 条 `cdn3.indevs.in` 地址。只测了这一个海外地点，不代表亚洲线路的速度。
- 已于 2026-11-08 删除的纬来日本、纬来育乐曾使用 RTMP；2026-10-26 从美国 runner 探测时 connect 没有回应，维护者当时实测可以播放。
- 翡翠台 4K 是 HEVC（H.265）编码，播放器不支持 HEVC 就播不了。
- issue 里 `live/hlt/` 和 `live/jade/` 两条都叫「华丽翡翠台」，但不是同一路信号：`hlt` 的编码参数和其他 Astro 频道一致，按路径名记作「华丽台」归马来西亚；`jade` 是另一路 720p 信号，沿用「华丽翡翠台」。没有看画面核对。
- 频道名、台标沿用原列表（台标为第三方地址）；2026-10-22 以后加入的条目没写台标。

## 怎么添加

新装和升级到支持默认订阅的版本后，「🌐 源管理 → 👤 自定义源」里会自动出现一条「来源于网络」订阅（只加一次；已经自己加过的不会重复加）。不想要就停用或删除这张卡片，删后重启不会再出现。部署时设了 `menableBuiltInSubscriptions=false` 的不会自动添加。

删掉后想再加回来：点「🌏 添加「来源于网络」列表」卡片，订阅名称和地址会自动填好，再点「📥 导入并保存」。也可以点「＋ 添加自定义源」，切到「订阅模式」，来源选「🌐 在线 URL」，粘贴下面这条直链：

```
https://raw.githubusercontent.com/akiralereal/iptv/main/from-the-web/from-the-web.m3u
```

拉取清单本身在大陆会自动回退 GitHub 镜像；第三方转发站通常仍需海外网络，平台分发及待确认 CDN 的可用性按各自线路判断。不想要的频道可在「我的频道」隐藏或调整分组。
