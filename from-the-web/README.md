# 来源于网络（from-the-web）

[from-the-web.m3u](from-the-web.m3u) 收的是**网络上流传的第三方转发源**，不是电视台官方地址，也不是本项目的内置源。这些频道原本在内置精选列表 `IPTV.m3u` 里，v4.7.0 逐条复核后整体移出：转发站不属于本项目，且在大陆直连全部不可达。放在这里只是方便有需要的用户自己添加，**本项目不维护、不保证可用，失效条目不作为 bug 受理**。

## 可用性（2026-09-07 复核）

- **大陆直连全部不可达**：转发站域名在电信 / 联通 / 移动家宽和腾讯 / 阿里机房共 9 个探针上均被 DNS 污染、无法建立连接。只有海外网络或路由器级全局代理环境才能播。
- 海外视角逐条拉取了清单与首个媒体分片，均能取到数据；MOMO 亲子台复核时已失效，未收录。
- 纬来日本、纬来育乐是 RTMP 地址，只验证了转发站在线，画面未验证，需要支持 RTMP 的播放器。
- 频道名沿用原列表（4gtv 系为繁体），台标沿用原列表的第三方地址。

## 怎么添加

后台「🌐 源管理 → 👤 自定义源」，点「🌏 添加「来源于网络」列表」卡片，订阅名称和地址会自动填好，再点「📥 导入并保存」即可。已经加过的话这张卡片不会出现。

没有这张卡片的旧版本，手动添加：点「＋ 添加自定义源」，切到「订阅模式」，来源选「🌐 在线 URL」，粘贴下面这条直链后「📥 导入并保存」：

```
https://raw.githubusercontent.com/akiralereal/iptv/main/from-the-web/from-the-web.m3u
```

拉取清单本身在大陆会自动回退 GitHub 镜像，但清单里的直播地址仍需能访问海外。不想要的频道可在「我的频道」隐藏或调整分组。
