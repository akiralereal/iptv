# 爱奇艺影视

主项目内的爱奇艺点播模块，位于管理页的“网络直播 → 爱奇艺影视”。打开“影视浏览页”可查看官网首页推荐、最热、最新、继续观看和电视剧选集。目录保持官网公共接口顺序，不保证与官网个性化首页一致。

## 播放和清单

以主项目管理员入口为前缀，例如 `http://NAS:1905/管理密码`：

- 浏览页：`/iqiyi-vod/`
- 全部 M3U：`/iqiyi-vod/playlist.m3u`
- 分别导出：`/iqiyi-vod/playlist.m3u?scope=recommend`、`hot`、`new`、`history`
- 统一弹幕元数据：`/iqiyi-vod/api/danmaku/v1/videos/{视频ID}`，ID 与分段地址由 M3U 的 `danmaku-url` 和元数据返回。

以上路径均需带主项目的访问前缀。影视清单独立于固定电视频道清单，不会把首页专辑写成固定频道。首次生成逐条核验，可能较慢：每轮最多新核验 20 部，其余下一轮继续；核验结论 6 小时内有效。播放器拉清单最多每 2 小时自动触发一轮，浏览页的按钮随时可以手动开始。电视剧每张卡片导出对应一集，不自动展开全部剧集。

仅确认完整观看权限、完整无加密 HLS 和前后段解码均成功后发布。试看、权益不足、不支持格式、核验失败均不进入清单。直接播放和分片也检查权限，缓存到期重新核验；明确失权立即停止旧缓存供流。网络失败与无完整权限分别显示。

每次解析都要用后台浏览器打开一次官方播放页，所以播放中的地址最长用 30 分钟（`IQIYI_VOD_TICKET_MAX_MS`）。官方签名只带签发时间、不写有效期：分片第一次被官方拒绝时，记下这次签名实际用了多久，之后提前 90 秒（`IQIYI_VOD_REFRESH_AHEAD_MS`）续期；第一次被拒那一下可能卡顿几十秒。续期只换签名，不再重复解码自检。账号失去某部内容的权限后，最晚在下一次续期（≤30 分钟）停止供流。闲置后停止后台续期。浏览器进度按账号、影片或剧集保存在服务本机，不回写官网历史。选集支持自动下一集。弹幕跟随播放和拖动同步，可关闭；M3U 中的弹幕关联需要 Ceau 等兼容客户端，普通播放器不会自动显示弹幕。

整个模块仅管理员可用：浏览页、历史、登录、清单、播放、分片和弹幕都要用管理员地址，用户令牌一律 403（播放用的是站长本人的会员）。没设访问密码时任何能连上端口的人都能用，建议先在系统设置里设访问密码。登录确认失效（官方账号接口确认）时进入后台「需要处理的提醒」。在源管理关掉模块后 30 秒内停止所有后台核验、续期和浏览器。后台浏览器计入全局上限 `mbrowserConcurrency`。

## 登录与 NAS

本机可打开官方网页登录。Docker／NAS 请在个人电脑登录爱奇艺官网后，在模块页面导入完整 Cookie 请求头或 Cookie JSON。账号校验成功后才替换专用登录副本；失败保留原登录态。每部内容仍须单独校验权益，会员身份不代表包含单场或专项付费内容。

运行目录默认是 `DATA_DIR/iqiyi-vod/.runtime`，可用 `IQIYI_VOD_RUNTIME_DIR` 指定。目录含登录凭据、只读云端历史缓存和本机进度，必须持久化并保持私有；不要提交 Git、放进镜像或打包公开。浏览器解析使用专用副本，不启动原有个人浏览器 profile。依赖 Chromium（沿用项目浏览器安装机制）；ffmpeg 可选，用于发布前解码开头和末尾各 5 秒做自检，Dockerfile 已安装，缺了就跳过自检。不再需要 Python。

从同一电脑的独立实验项目迁移，可手动运行：

```sh
node scripts/iqiyi-vod-import-local-snapshot.mjs --source /绝对路径/snapshot-path.txt --progress /绝对路径/history-progress.json
```

该命令只读备份源 Cookie 数据库，不覆盖已有目标登录档。Chrome 加密 Cookie 不保证跨操作系统可用；迁移 NAS 请使用 Cookie 导入。

## 测试

`npm run test:iqiyi-vod` 使用本地夹具验证目录、历史、选集、进度、权限隔离、续期、M3U 和统一弹幕，不访问其他平台。实际联调只启用爱奇艺模块，并使用独立 DATA_DIR，避免触发其他来源采集。

## 冷启动预热与恢复

打开管理员影视页时启动一轮预热：首页各分类读取完成即开始核验，不等云端历史。维持现有每轮新核验上限及订阅触发冷却，不在模块启动或定时更新时自动打开全部影片。页面只有在对应分类有有效条目后启用 M3U 导入链接；完全无缓存仍需完成官网核验，建议等待就绪再导入。

运行目录保存签名校验的私有热缓存，只恢复登录凭据指纹一致、仍处于原票据有效期内的完整授权结果。重启不会延长票据或权益期限，保留清晰度及分片版本；过期、失权、缓存被改动或重新检查/导入账号时失效。失效后仍按现有权限和自动续期策略核验。缓存及签名密钥与 Cookie 一样仅放私有运行目录，不进 Git 或镜像。
